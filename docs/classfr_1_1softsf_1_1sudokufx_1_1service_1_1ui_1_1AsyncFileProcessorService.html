Detailed Description

Service to execute file-processing tasks asynchronously with JavaFX UI feedback.

Displays a spinner and toast messages during task execution. Handles success and error reporting automatically on the JavaFX Application Thread.

Executes a file-processing task asynchronously with spinner and toast feedback.

Configures a daemon thread to handle the background processing, manages UI indicators (spinner and toaster), and returns the Task instance to allow for lifecycle control, such as manual cancellation.
