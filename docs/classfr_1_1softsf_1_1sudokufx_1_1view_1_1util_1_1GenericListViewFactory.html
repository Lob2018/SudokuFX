Detailed Description

Factory responsible for configuring ListView components with custom cells and bindings.

Centralizes repetitive setup logic for UI components in the main view, including:

  • Rounded clipping for visual consistency
  • Custom cell factories with accessibility and confirmation support
  • Bidirectional selection binding between the view and its ViewModel

This class is designed to be injected via Spring and used to streamline menu initialization.

Configures a ListView to update the provided Property only upon explicit user confirmation.

This method sets up event handlers for ENTER/SPACE key presses and double-click mouse events to commit the current list selection to the model. This prevents premature updates during list navigation.
