Detailed Description

Interface defining methods to encrypt and decrypt strings using AES-GCM (Galois/Counter Mode).

Implementation of the ApplicationKeystore.IEncryptionService interface using AES-GCM (Galois/Counter Mode) encryption with secure char[] handling.
